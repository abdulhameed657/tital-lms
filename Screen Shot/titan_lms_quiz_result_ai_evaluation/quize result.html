Which data structure offers O(1) space complexity for tracking frequency?

Your Answer: Dynamic Array

Correct Answer: Fixed Hash Map (or Array-based Buffer)

Incorrect. A dynamic array grows with input size, yielding O(n) space. Frequency tracking with a limited range should utilize a fixed-size buffer.

Which mechanism prevents race conditions in shared memory?

Your Answer: Mutex (Mutual Exclusion)
